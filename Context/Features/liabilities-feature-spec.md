# Liabilities Feature Spec

## Goal

Allow users to track debts and obligations.

## Liability Types

- Mortgage
- Bank loan
- Credit card debt
- Family loan
- Other liability

## Initial Scope

Planned for Phase 2.

Users should be able to:
- Add liability
- Edit current balance
- Set monthly payment
- Set interest rate
- Set maturity date
- Add notes
